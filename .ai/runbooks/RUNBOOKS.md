# Runbooks

Los procedimientos operativos viven en `.ai/skills/SKILLS.md`, que es la
fuente única para flujos de electrónica, nodos, viewport, UI, traducciones,
debug y paneles nativos.

Este archivo se conserva como puntero para herramientas que todavía escanean
la carpeta `runbooks`; no debe duplicar recetas ni introducir rutas antiguas.

Consulta primero:

- `skill: agregar-panel-nativo` para superficies RafUI y hosts.
- `skill: agregar-feature-electronica` para schematic, PCB, componentes y DRC.
- `skill: agregar-nodo-visual` para nodos y ejecución.
- `skill: mejorar-viewport` para render, proyección y CAD.
- `skill: traducir-ui` para i18n JSON.
- `skill: debug-compilacion` para validaciones.
